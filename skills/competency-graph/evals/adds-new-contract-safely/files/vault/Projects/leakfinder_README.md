# leakfinder

Open-source Python library for detecting leaks from district-metered-area night flows.

- Minimum-night-flow and rolling z-score detectors, plus an isolation-forest option (scikit-learn).
- Reads CSV or PostGIS meter tables; outputs GeoJSON for ArcGIS or QGIS.
- 86 pytest tests; MIT licence.

Created 2022-03-14; last release 0.6.0 on 2024-05-30. https://github.com/tvarga/leakfinder
